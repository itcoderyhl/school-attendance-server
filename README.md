# school-attendance-server
基于SpringBoot3+Vue3前后端分离的校园考勤管理系统（源码+文档），系统包含管理员、教师、员工角色，功能如下： 管理员：首页统计（过去7天未签到人数、学生统计）；学院管理；学生管理；教师管理；课程管理；选课管理；考勤管理；考勤打卡；请假管理；留言管理；公告管理；修改个人资料；修改密码。 教师：课程管理；选课管理（查看选课学生）；考勤管理（发起考勤）；考勤打卡（查看打卡学生）；公告管理；修改个人资料；修改密码。 学生：课程管理；选课管理；考勤打卡；请假管理；留言管理；公告管理；个人信息修改；密码修改。 系统界面美观大方，功能丰富，使用了SpringBoot3、Vue3、Element-Plus、Echarts等技术栈。
